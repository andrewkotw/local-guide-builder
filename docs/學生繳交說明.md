# 學生繳交說明

完成網站後，請照這 5 步做：

1. 到最後一步，先看一次電腦版和手機版預覽。
2. 勾選四個隱私確認項目。
3. 按「下載交給老師的網站壓縮檔」。
4. 找到剛下載的 ZIP，例如 `景點-Sea-Breeze-Trail-海風觀察隊.zip`。
5. **不要解壓縮、不要改檔名**，直接把整個 ZIP 交給老師。

請注意：

- 「網站壓縮檔」是交作業用的。
- `.localguide` 是你下次繼續修改用的作品備份，也請自己留一份，但不要把它當作正式作業。
- 如果交出後又修改了內容，請重新下載 ZIP，再告訴老師這是新版。
- ZIP 裡的檔案不要刪除，否則照片、影片或版面可能不見。
